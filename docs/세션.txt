# 역할 UUID 주소록 — 탭 세션은 첫 행동으로 echo "<역할> $CODEX_THREAD_ID 탭 보고→<상대>" >> docs/세션.txt  (워커의 상대는 오케)
# 보낼 때: codex queue --thread <UUID> --message "[<나>→<상대>] …"   「Queued」는 접수, 반영은 상대의 답으로 확인
# B(앱 chat)일 때: 탭 = chat. 줄은 echo "<역할> <chat ID 또는 -> 탭 보고→<상대>" (ID 는 /status). 보낼 땐 queue 대신 docs/우편함/<받는역할>.md 끝에 [<나>→<상대> HH:MM] 내용 을 append 하고 사용자에게 「<받는역할> chat 에 우편함」
# 서브에이전트는 여기 등록하지 않는다(부모 반환). 탭을 닫으면 그 줄 끝에 (닫힘) — 닫힌 세션에 queue 는 가지 않는다
# 통제 메시지(연장·중단)는 오케가 (닫힘) 없는 줄 전부에 보낸다
